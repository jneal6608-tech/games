# Catangle

A cat-themed escape puzzle for Android. Tap a cat with a clear path and it runs home.

- Play in a browser: serve `web/` (for example `python3 -m http.server 8765 --directory web`) and open it at phone size.
- Build for Android: see `TECHNICAL_NOTES.md`.
- Project documents: `MARKET_RESEARCH.md`, `COMPETITOR_ANALYSIS.md`, `GAME_DESIGN.md`, `TECHNICAL_NOTES.md`, `PROGRESS.md`, `NEXT_STEPS.md`, `HANDOFF_PROMPT.md`.
- Store materials: `docs/store/`. Marketing clips and playbook: `marketing/`.

All art is drawn in code and all sound is synthesised. The only third-party asset is the Fredoka font (SIL Open Font License, `web/fonts/OFL.txt`).
